# Bank Ledger System

Simple Python Bank Ledger project with user input and account details.

### Files:
* `main.py` — Takes user input to create an account and runs a simple menu (deposit, withdraw, show account details).
* `ledger-classe.py` — Defines `Account`, `BankLedger`, and menu helper functions.
* `test.py` — Tests the `Account` and `BankLedger` classes.

### To run:
```bash
python3 main.py
```
